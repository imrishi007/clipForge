# Implementation checkpoints

1. A: Next/React strict TypeScript shell, themes, original sample, test harness. Gate: static/unit/browser and theme screenshots.
2. B: IndexedDB repository, dashboard/library/import, every auxiliary route and project controls. Gate: CRUD, persistence, navigation and themes.
3. C: single-source editor, trim/split, crop, captions, audio, history and autosave. Gate: edit/reload/browser and both themes.
4. D: FastAPI, SQLAlchemy, Alembic, validated media ingestion, safe streams, campaigns and edit revisions. Gate: Python/API and real fixture tests.
5. E: sequential persistent local render queue, ASS/SRT, FFmpeg, cancellation/retry. Gate: genuine output probing, no-audio/corruption, batch and captions.
6. F: frontend/backend integration, recovery and final regression. Gate: browser upload-to-export, full checks/build, evidence and limitations.

Each bounded change is followed by tests before work continues. No AI results will be inferred for real uploads. Missing capabilities remain explicitly unavailable.
